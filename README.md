## Overview

Minecraft Forge is the most widely used modding API and library for Minecraft Java Edition, providing the standardized hooks, event system, and inter-mod compatibility layer that tens of thousands of mods depend on. As the foundation of the Java modding ecosystem for over a decade, nearly every major Minecraft content mod supports Forge, making it the default choice for modpack players.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Minecraft Forge** delivers the features you need in a clean, intuitive package.

> Official website: [minecraftforge.net](https://minecraftforge.net)
